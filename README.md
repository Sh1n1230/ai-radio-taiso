# ai-radio-taiso

昔のAIが作ったような，さりげなく壊れたラジオ体操のアニメーション試作です．`index.html` 1枚で動き，外部ファイルは使いません．

## 動かし方

`index.html` をブラウザで開き，「はじめる」を押します．音はボタンを押した時点で鳴り始めます．アナウンスはブラウザの音声合成（ja-JP）で読み上げ，使えない環境では字幕だけになります．

## 方針

ほぼ普通の体操を続け，各運動に小さな異常を1つだけ入れます．アナウンスは異常に一切触れません．

| 運動 | 異常 |
| --- | --- |
| 背伸び | 3回目に腕だけ上に置き去りになり，次の拍で戻る |
| 腕を振って足をまげる | 8回目だけ左膝が逆に曲がる |
| 腕をまわす | 右腕だけ1周多く回る |
| 胸の運動 | 5拍目から頭が半個ぶん左にずれたまま |
| 横曲げ | 後半は影だけ反対側に曲がる |
| 前後に曲げる | 最後だけ反りすぎる．カウントが「しち，しち」で終わる |
| ねじる | 体は戻るのに顔だけ横を向いたまま |
| 腕を上下にのばす | アナウンスは「次は首の運動です」 |
| 両足でとぶ | 1回だけ着地が半拍遅れる |
| 深呼吸 | 最後の1回は吐かないまま終わる |

## 構成

- テンポは126 BPM．Web Audio APIで伴奏を合成し，映像も同じ時計で動かします．
- 運動はスクリプト内の `MOVES` 配列で定義します．1運動16拍で，`pose(b)` が拍 `b` の姿勢を返します．
